# Customer App (Spring Boot + MySQL)

A simple **one-page CRUD** web application built with **Java Spring Boot + Thymeleaf** and **MySQL**.

---

## Features
- Create customer records (Name, Email, Phone)
- View all customers in a table
- Edit existing customer records
- Delete customer records
- Persist data in MySQL database
